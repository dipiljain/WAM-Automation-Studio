Wealth AI Studio User Guide

Wealth AI Studio is a Salesforce workspace for advisors, portfolio teams, compliance, operations, distribution, service, and executives. It turns AI recommendations, insights, risk signals, workflows, and autonomous agent runs into role-specific actions.

Org: wm-studio-org App: Wealth AI Studio Guide date: 2026-07-02 Coverage: UC-1 to UC-40

Quick start

1
Open Salesforce App Launcher. Search for Wealth AI Studio and open the app.
2
Choose a persona page. Use Advisor Home, Compliance Home, or Executive Home from the app navigation.
3
Select a client or household. Most action widgets include a Client / Household dropdown. For demos, select Sharma Family Office first.
4
Run an AI action. Click an action button such as Run Proposal Copilot or Run Portfolio Monitoring.
5
Review the result. The widget refreshes, shows a success toast, updates KPI tiles, and adds a queue item.
6
Audit the run. Open AI Agent Runs, AI Recommendations, or AI Insights to inspect records.
Best demo account: Start with Sharma Family Office. It contains UC-1 to UC-40 tagged agent runs and rich demo artifacts across all widgets.

Widget guide

Advisor Cockpit

Shows high-priority recommendations, new insights, briefings generated today, and at-risk clients. Use it to begin an advisor day and decide which clients need attention.

Records used: AI Recommendations, AI Insights, Advisor Briefings, Client Health Scores.

Advisor Action Center

Select an account and run briefing, relationship intelligence, next best action, and score refresh actions. The widget creates briefings, insights, recommendations, and updated scores.

Use cases: UC-1, UC-4, UC-5, UC-10, UC-11, UC-12, UC-22, UC-23.

Portfolio Copilot Panel

Runs portfolio health, review, commentary, and risk exposure detection. Watch alert and signal lists update after each action.

Use cases: UC-6, UC-7, UC-8, UC-9.

Ops Compliance Workbench

Combines distribution, compliance, and operations actions. It creates referral predictions, compliance findings, and workflow executions.

Use cases: UC-13 to UC-21.

Growth Service Command Center

Launches scale use cases such as proposal copilot, referral intelligence, cross-sell, scenario analysis, service resolution, attrition, surveillance, reconciliation, and cash movement intelligence.

Example: Select Rao Global Family Trust and click Run Proposal Copilot. The system creates a successful Advisor agent run plus a new Proposal recommendation. If the latest health score is below 65, priority is High.

Use cases: UC-24 to UC-32.

Autonomy Control Tower

Runs autonomous advisor, service, operations, compliance, prospecting, branch manager, portfolio monitoring, and personalized engagement cycles. It shows pending approvals, escalations, autonomous run count, and active workflows.

HITL logic: Advisor, compliance, prospecting, and personalized engagement cycles can create pending approval items.

Use cases: UC-33 to UC-40.

End-to-end demo story

1
Executive opens the conversation. Start on Executive Home. Explain pipeline value, agent run success, average client health, and compliance exposure.
2
Advisor acts on the priority household. Go to Advisor Home, select Sharma Family Office, and show recommendations, insights, briefing, score refresh, and growth actions.
3
Portfolio team explains risk. Use Portfolio Copilot to generate health analysis, commentary, and risk exposure signals.
4
Compliance and operations resolve work. Open Compliance Home. Use Ops Compliance Workbench to show KYC, AML, regulatory monitoring, onboarding, document, and workflow execution.
5
Scale growth and service. In Growth Service Command Center, run proposal copilot, cross-sell, service resolution, attrition, surveillance, reconciliation, and cash movement scenarios.
6
Finish with autonomy and guardrails. In Autonomy Control Tower, show autonomous runs, pending HITL approvals, escalations, and workflow execution. Explain that autonomy is supervised, auditable, and role-aware.

Daily usage plays

Advisor morning routine

  1. Open Advisor Home.
  2. Review high-priority recommendations and at-risk clients.
  3. Select the highest priority account.
  4. Generate briefing and next best action.
  5. Run proposal or cross-sell action if relevant.

Compliance review routine

  1. Open Compliance Home.
  2. Review open and escalated findings.
  3. Run KYC, AML, or surveillance actions.
  4. Check Autonomy Control Tower for pending approvals.
  5. Drill into AI Agent Runs for audit details.

Executive review routine

  1. Open Executive Home.
  2. Review pipeline value and agent adoption.
  3. Inspect growth queue and service/control indicators.
  4. Open Autonomy Control Tower for escalations.
  5. Use object tabs for supporting evidence.

Operations routine

  1. Use Ops Compliance Workbench or Growth Service Command Center.
  2. Run onboarding, document extraction, workflow, reconciliation, or cash actions.
  3. Review Workflow Executions.
  4. Escalate failed or running workflows as needed.

Troubleshooting

Issue What to check Expected fix
Persona card is hidden User may not have the related role permission set. Assign WAM Role - Advisor, WAM Role - Compliance, or WAM Role - Executive.
Action button is disabled No client selected, widget is loading, or record context is missing. Select an account from the dropdown and wait for loading to finish.
Counts do not change after an action The count may be filtered to a specific status or type. Open the related queue or object tab to confirm the new record.
Pending approvals are visible Autonomous HITL flows intentionally create pending items. Open AI Agent Runs and review records with HITL Status = Pending.
No demo accounts appear Demo seed data may not have been loaded in the org. Run the seed script from scripts/apex/seed_10_accounts_uc1_uc40.apex.
Note: This accelerator creates Salesforce records for demo and validation purposes. Review generated records before using the data in a production-style presentation.
