# Diagrams (Mermaid) — importable

Portable, version-controlled Mermaid (`.mmd`) sources for the Wealth AI Studio. They render natively on GitHub and can be **imported** into FigJam (Figma's Mermaid import), Miro, draw.io, Notion, Confluence, and the Mermaid Live Editor.

> Note: these are schematic diagrams (structure, flows, relationships). They complement, but do not replace, the high-fidelity Figma UI screens in [D7](../docs/07-ux-design-specs.md)/[D8](../docs/08-figma-design-package.md).

## How to import
- **FigJam/Figma:** use FigJam's "Diagram" / Mermaid import (or a Mermaid plugin); paste the file contents.
- **Miro:** Mermaid plugin → paste contents.
- **draw.io:** Arrange → Insert → Advanced → Mermaid → paste contents.
- **GitHub/Notion/Confluence:** renders from a fenced ```mermaid``` block (contents of the file).
- **Mermaid Live:** https://mermaid.live → paste to preview/export SVG/PNG.
